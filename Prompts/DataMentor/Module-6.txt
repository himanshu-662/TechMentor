==================================================

==================================================

==================================================
2. DETECTION METHODS
==================================================

Implement:

A. IQR
B. Z-score
C. Modified Z-score

IQR:

IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR
Upper Bound = Q3 + 1.5 × IQR

Make multiplier configurable, default 1.5.

Z-score:

Z = (x - mean) / standard_deviation

Default threshold:
abs(Z) > 3

Make threshold configurable.

Modified Z-score:

Modified Z = 0.6745 × (x - median) / MAD

Default threshold:
abs(Modified Z) > 3.5

Make threshold configurable.

Handle edge cases safely:
- empty columns
- all NaN
- constant columns
- zero standard deviation
- MAD = 0
- very small datasets

3. METHOD RECOMMENDATION
==================================================

Create deterministic recommendation logic.

Recommendations must use actual dataset statistics.

Example:

If numerical column is strongly skewed:
recommend IQR.

If approximately symmetric and appropriate for mean/std:
recommend Z-score.

Every recommendation must contain:

- reason
- evidence
- alternative methods

Do NOT use an LLM for recommendations.

8. TREATMENT OPTIONS
==================================================

Implement:

A. Keep
B. Remove
C. Cap/Winsorize
D. Custom Bounds

KEEP:
Do not change the dataset.

REMOVE:
Remove rows containing selected outlier values.

CAP:
Replace values outside the selected bounds with the corresponding boundary.

CUSTOM BOUNDS:
Allow the user to specify lower and upper bounds.

All treatments must require explicit user confirmation.
