==================================================
3. STANDARDIZATION
==================================================

Formula:

z = (x - mean) / standard_deviation

Explain:
- what it does
- why it is useful
- when to use it
- when not to use it
- ML algorithms affected by scale
- limitations

Show real dataset calculations when requested.

==================================================
4. MIN-MAX SCALING
==================================================

Formula:

x' = (x - min) / (max - min)

Default range:
0 to 1

Allow configurable feature range.

Example:
[0, 1]
[-1, 1]

Validate constant columns safely.

==================================================
5. ROBUST SCALING
==================================================

Concept:

x' = (x - median) / IQR

Use RobustScaler.

Explain connection with Phase 6:
Robust scaling is less sensitive to extreme values because it uses median and IQR.

==================================================
6. LOG TRANSFORMATION
==================================================

Support log1p for non-negative values.

Explain:

log1p(x) = log(1 + x)

Use it to reduce strong positive/right skewness where appropriate.

Handle:
- zero
- negative values
- NaN

Do not blindly apply log to negative values.

If negative values exist, provide a clear educational error and suggest considering Yeo-Johnson.

==================================================
7. POWER TRANSFORMATION
==================================================

Implement Yeo-Johnson.

Yeo-Johnson must support:
- positive
- zero
- negative

Implement Box-Cox only when all non-missing values are strictly positive.

If zero or negative values exist, reject Box-Cox with a clear educational explanation.

==================================================
9. RECOMMENDATION ENGINE
==================================================

Create deterministic recommendations.

Examples:

Strong positive skew:
→ consider log1p

Many extreme values:
→ consider RobustScaler

Approximately symmetric numerical feature:
→ consider StandardScaler depending on downstream algorithm

Need bounded range:
→ consider MinMaxScaler

Positive/zero/negative and non-normal distribution:
→ consider Yeo-Johnson

Recommendations must contain:

method
reason
evidence
alternative methods

Do not automatically apply recommendations.

Do not use an LLM.
