==================================================
1. CORE PRINCIPLE
==================================================

Every important statistical observation should have an appropriate visual explanation when meaningful.

Do not generate charts simply because they are technically possible.

Every chart should answer a question.

Workflow:

DATA
→ PROFILE
→ UNDERSTAND TYPES
→ SELECT VARIABLES
→ RECOMMEND VISUALIZATION
→ GENERATE
→ INTERPRET
→ LEARN

==================================================

25. VALIDATION
==================================================

Reject:

- invalid columns
- incompatible chart types
- invalid aggregation
- too many pair-plot features
- invalid dataset version
- invalid correlation method

Provide educational errors.

==================================================
26. PERFORMANCE
==================================================

Datasets may contain many rows.

Do not render millions of points directly in the browser.

Implement reasonable sampling/downsampling for large visualizations.

Clearly indicate when sampling is being used.

Example:

"Displaying a representative sample of 50,000 rows from 2,000,000 rows."

Never silently sample.
