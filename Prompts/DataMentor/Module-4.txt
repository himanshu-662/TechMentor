PHASE 4 — LEARNING & EXPLANATION ENGINE

Project:
DataMentor AI

IMPORTANT:

DataMentor AI is a learning-first data preparation platform.

Its purpose is not only to automate data preprocessing.

It must help beginners understand:

- what is happening
- why it is happening
- what the detected concept means
- why it matters
- what alternatives exist
- when a technique is useful
- what happens next in the data pipeline

Phase 2 and Phase 3 are already implemented and working.

DO NOT break existing functionality.

==================================================
PHASE 4 OBJECTIVE
==================================================

Build a structured educational knowledge and explanation
engine that connects the profiling results from Phase 3
with beginner-friendly learning content.

IMPORTANT:

Do NOT add the AI chatbot yet.

Do NOT add an LLM.

Do NOT add RAG.

Use structured, deterministic educational content.

The future chatbot will reuse this knowledge layer.

==================================================
2. STANDARD CONCEPT STRUCTURE
==================================================

Every concept must contain:

- concept_id
- title
- short_definition
- beginner_explanation
- intermediate_explanation
- technical_explanation
- why_it_matters
- real_world_example
- ml_impact
- common_methods
- when_to_use
- when_not_to_use
- common_mistakes
- interview_tip
- related_concepts

Use structured Python models/dataclasses/Pydantic models.

Do not put large educational content directly inside
React components.

==================================================
6. EXPLANATION API
==================================================

Create:

GET /api/education/concepts/{concept_id}

Return the complete structured concept explanation.

Also create:

GET /api/education/concepts

Return a list of available concepts.

==================================================
7. CONTEXTUAL EXPLANATION API
==================================================

Create:

POST /api/education/explain

Request:

{
  "concept_id": "...",
  "dataset_id": "...",
  "column": "...",
  "level": "beginner"
}

The service should combine:

1. General concept knowledge
2. Actual dataset profiling information
3. Current column information

Return:

- title
- explanation
- dataset evidence
- why it matters
- next step
- related concepts

IMPORTANT:

Do not modify the dataset.

==================================================
8. DATASET EVIDENCE
==================================================

For contextual explanations, use real profiling results.

Example:

Concept:
missing_values

Column:
income

Dataset evidence:

missing_count = 870
missing_percentage = 8.7

The explanation should say that the actual dataset
contains 870 missing income values.

Never fabricate dataset values.
