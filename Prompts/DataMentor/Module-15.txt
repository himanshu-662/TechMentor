# 5. CORE DESIGN PRINCIPLE

Whenever possible:

> **Explain the user's actual dataset instead of giving a generic textbook answer.**

Bad:

```text
StandardScaler transforms data so that it has mean 0
and standard deviation 1.
```

Better:

```text
Your dataset contains features with very different scales.
For example, income may range from thousands to hundreds
of thousands while age ranges from 18 to 70.

StandardScaler makes these numerical features comparable
in scale, which can be useful for algorithms that are
sensitive to feature magnitude.
```

The second type of answer should be used whenever the required context exists.

# 37. EXAMPLE DATASET-SPECIFIC ANSWER

For:

```text
Why did DataMentor use median imputation?
```

If supported by actual context:

```text
The `income` column contained missing values.

Median imputation was selected because:

• `income` is numerical.
• Missing values were present.
• The median is less affected by extreme values than the mean.

In your dataset:
Missing values before treatment: 128

The operation was applied in version v3.

Important:
This does not mean median imputation is always the best
choice. The appropriate method depends on the data distribution
and the reason values are missing.
```

Do not generate values that do not exist in context.


# 39. MODEL COMPARISON QUESTIONS

```text

Difference:
0.07

feature relationships, preprocessing requirements, and the
types of patterns each model can represent.

The observed metric difference does not by itself establish
the exact cause.
```
